# 💰 Simple Expense Tracker

مشروع بسيط لإدارة وتتبع المصروفات باستخدام TypeScript، يتيح تسجيل المصروفات وتحليلها من خلال مجموعة من العمليات الحسابية والوظائف البرمجية.

## ✨ مميزات المشروع

- تخزين المصروفات في مصفوفة من الكائنات.
- إضافة مصروفات جديدة.
- حساب إجمالي المصروفات.
- حساب متوسط قيمة المصروفات.
- تحديد أعلى مصروف.
- تصفية المصروفات حسب الفئة.
- عرض البيانات باستخدام `console.table()`.

## 🛠️ التقنيات المستخدمة

- TypeScript
- Node.js
- npm
- tsx
